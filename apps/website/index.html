What this is

A plain, standards-based chat address for normal clients.

Accounts are not open-registration. Ask for an invite, wait for human review, then register with the one-time link.

Client setup

Your future address will look like name@xmp.pm. Install a client, request an invite, then register with the one-time link.

Most clients should auto-detect server settings from the domain xmp.pm.

Capabilities

  • Multi-device message sync
  • HTTP File Upload
  • Offline message delivery
  • Multi-user chat rooms
  • OMEMO
  • Audio/Video Call Support

New to XMPP?

XMPP is federated chat: like email, your account can talk to people on other compatible servers.

Recommended clients: Conversations on Android, Monal on iOS/macOS, Gajim on Windows/Linux/macOS, and Dino on Linux.

Privacy / retention

Service data normally stays in Switzerland. Oracle is based in the United States and may have to respond to lawful government requests.

OMEMO-encrypted message content is unreadable to the server by design. Connection and communication metadata is not end-to-end encrypted and may be processed or retained.
